### AI (Nándi + aki akar AI-zni)

**Cél:** Ollama setup + basic AI analysis teszt

**Feladatok:**

- Ollama Docker Compose service indítása

  ```bash
  docker-compose up -d ollama
  docker exec -it virtplc-ollama ollama pull llama3:8b
  ```

- Ollama API tesztelése (basic prompt)

  ```bash
  curl http://localhost:11434/api/generate -d '{"model":"llama3:8b","prompt":"Test"}'
  ```

- AI service Node.js szerver indítása (`npm run dev`)
- Ollama client integration ellenőrzése
- REST endpoint teszt: `/api/analysis/analyze`
- WebSocket connection teszt (basic broadcast)

**Deliverable:**

- Ollama fut és válaszol Llama3 8B-vel
- AI service API működik (analyze endpoint)
- WebSocket stream működik (test message)

**Blocker:** Nincs (lokálisan tesztelhető)

**Resource igény:** GPU (optional, de ajánlott), minimum 8GB RAM Ollama-hoz
