# General format of diary entries

## Naming convention

Keep diary filenames short and consistent so entries are easy to sort and find.

- Date-first format: YYYY-MM-DD
- Optional suffix: a short slug describing the meetup or topic

Examples:

- `2025-10-10-meetup.md` (meetup on Oct 10, 2025)
- `2025-10-10-devops.md` (meetup focused on DevOps)

Guidelines:

- Use ISO date at the start so files sort chronologically.
- Separate date and slug with a single hyphen.
- Use lowercase letters, numbers and hyphens only in slugs (no spaces, no underscores).
- Keep the slug concise (1–4 words).
- Prefer Markdown (`.md`) for entries.

Minimal file structure suggestion (in the file body):

- Title line: `# YYYY-MM-DD — Short title`
- Optional metadata block (YAML front-matter) with keys like `location`, `attendees`, `tags`.
- Short summary paragraph followed by bullet points or sections for notes, decisions, and action items.

Other stylistic rules may be added as we advance...
