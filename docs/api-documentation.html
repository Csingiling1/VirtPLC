🏗️ Microservice Architecture

The VirtPLC platform follows a modern microservice architecture designed for scalability, resilience, and maintainability:

Architecture Overview

  • API Gateway: Nginx reverse proxy with rate limiting
  • Authentication: JWT-based with OAuth2 support
  • Data Layer: PostgreSQL + TimescaleDB for time-series
  • Messaging: RabbitMQ MQTT for real-time data
  • Caching: Redis for session management and performance
  • Monitoring: Prometheus metrics across all services
  • AI/ML: Ollama models with MCP for intelligent analytics

Key Features:

  • Scalability: Services can be scaled independently based on load
  • Resilience: Circuit breakers and health checks prevent cascade failures
  • Observability: Comprehensive logging, metrics, and tracing
  • Security: JWT authentication, CORS, and secure communication
  • Real-time: WebSocket and MQTT for live data streaming
  • AI Integration: Machine learning models for predictive maintenance
