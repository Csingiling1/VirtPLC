# User Stories

## Warehouse Operator

**As a** Warehouse Operator, with access to a tablet connected to the PLC system,  
**I should be able to** monitor real-time equipment and shelf status, and receive alerts when anomalies occur (e.g., temperature too high, shelf overloaded).

---

## AI Analyst / System

**As an** AI System, with access to sensor and camera data,  
**I should be able to** segment the 3D space into shelves, items, and zones, and predict potential maintenance or logistic issues.

---

## Maintenance Technician

**As a** Maintenance Technician, with permissions to control PLC-connected machinery,  
**I should be able to** simulate and schedule repairs or maintenance within the virtual model and update logs directly from the 3D interface.

---

## Operations Manager

**As an** Operations Manager, with an overview dashboard,  
**I should be able to** view performance metrics, generate reports, and query the system using natural language (e.g., "Which aisle has the lowest turnover this week?").

---

## Administrator

**As an** Administrator, with full system privileges,  
**I should be able to** configure access levels, connect new sensors/PLCs, and manage AI model updates and data storage policies.
